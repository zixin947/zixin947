## 我的项目

### [dsh-compact](https://github.com/zixin947/dsh-compact)

面向 DeepSeek Harness 的上下文压缩插件，支持自动压缩、手动压缩、工具结果裁剪与有界溢出恢复。

基于官方压缩引擎实现，提供独立的 Agent 插件入口与配置界面。

[查看代码与使用说明](https://github.com/zixin947/dsh-compact#readme)

## 技术与工程

**AI / LLM：** DeepSeek Harness、Agent 插件、上下文压缩、模型 Provider、工具调用。

**工程实现：** JavaScript、TypeScript、Node.js、HTTP / SSE、Git、GitHub Actions、回归测试。

### 全栈基础

Java · Spring Boot · Vue 3 · MySQL · Electron
